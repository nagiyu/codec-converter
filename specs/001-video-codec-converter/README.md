# ビデオコーデックコンバータ機能

## 概要

このディレクトリには、ビデオコーデックコンバータ機能の設計ドキュメントと実装計画が含まれています。

ビデオコーデックコンバータは、ユーザーが動画ファイルをアップロードし、現在のコーデックを検出・表示し、異なるコーデックを選択して変換した動画ファイルをダウンロードできる Web アプリケーションです。

## 主要機能

- 動画ファイルのアップロード（ファイルピッカーおよびドラッグ&ドロップ対応）
- コーデックとメタデータの自動検出・表示
- 複数のターゲットコーデック（H.264, HEVC/H.265, VP9, AV1 など）への変換
- 変換進捗の表示と ETA の提供
- 変換済みファイルのダウンロード
- エラーハンドリングと明確なフィードバック

## 開発の進め方

### MVP（Minimum Viable Product）

MVP の範囲は **ユーザーストーリー 1（US1）** のみです：

- セットアップタスク：T001-T005
- 基盤タスク：T006-T011
- US1 実装タスク：T012-T019

**目標**：単一動画の変換機能を実装し、エンドツーエンドで動作を検証する。

### 推奨される実装順序

1. **フェーズ 1: セットアップ**
   - Next.js と Batch のスキャフォールド作成
   - CI ワークフロー骨子の追加
   - リンティング・フォーマット設定

2. **フェーズ 2: 基盤**
   - インフラ（S3, DynamoDB, IAM）の CloudFormation テンプレート作成
   - データモデルの実装
   - API ルートのスタブ作成

3. **フェーズ 3: ユーザーストーリー 1（P1 - MVP）**
   - サービスレイヤーの実装
   - UI コンポーネントの実装
   - Batch ワーカーの実装
   - エンドツーエンド統合

4. **フェーズ 4-6: 追加機能と仕上げ**
   - US2: ドラッグ&ドロップと進捗表示
   - US3: エラーハンドリング
   - ドキュメント更新とテスト追加

### 並列作業の可能性

複数の開発者が同時に作業できる領域：

- UI コンポーネント（`web/nextjs/src/app/convert/*`）
- Batch ワーカー（`batch/*`）
- インフラテンプレート（`infra/*`）

## アーキテクチャ概要

- **フロントエンド**: Next.js (App Router)
- **バックエンド**: Next.js API Routes (Lambda コンテナ)
- **ストレージ**: Amazon S3（アップロード・出力）
- **データベース**: Amazon DynamoDB（メタデータ・ジョブステータス）
- **処理**: AWS Batch（ffmpeg による動画変換）
- **CI/CD**: GitHub Actions + CloudFormation

## サポートされるコーデック

（MVP での対応予定）

- **入力**: 一般的な動画フォーマット（H.264, HEVC, VP8, VP9 など）
- **出力**: H.264 (mp4), HEVC/H.265, VP9 (webm), AV1

※ 正確な対応コーデックリストは実装時に確定します。

## 制約事項

- MVP のファイルサイズ上限: 100MB（推奨）
- 変換時間の目標: 5 分以内（90% のケース）
- 認証: MVP では不要（パブリックアクセス）
